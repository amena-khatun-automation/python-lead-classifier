# python-lead-classifier
Python project for classifying leads

## Project Overview
This is a beginner Python project that classifies leads based on their scores.

## Features
- Add new leads
- Calculate lead status
- Classify leads as Hot, Warm, or Cold
- Store lead data using JSON

## Technologies Used
- Python
- JSON
- Git
- GitHub

## Lead Classification Rules
- Score 80 or above = Hot
- Score 60 or above = Warm
- Below 60 = Cold

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Run:

```bash
lead_classifier.py
```
